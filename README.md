## 📖 Overview

A native desktop file manager built with **Tauri** (Rust backend) and **React** (frontend). Browse, manage, and preview files locally with a modern UI.

## 🛠 Tech stack

`Tauri` · `React` · `TypeScript` · `Tailwind` · `Vite` · `Rust`

## 📦 Quick start

```bash
git clone https://github.com/m3rashid/file-explorer.git
cd file-explorer
pnpm install
pnpm tauri dev
```
